# NeuralTutor - AI Learning Platform

## Quick Start

1. Install Flask:
   pip install flask

2. Run the app:
   python app.py

3. Open browser: http://localhost:5000

## Pages
- /          → redirects to login
- /login     → Login page
- /register  → Register page
- /about     → About page
- /dashboard → Subject selection (after login)
- /quiz/<subject> → Quiz + Learning Path

Python Programming, Machine Learning, Data Science,
Web Development, Artificial Intelligence, Mathematics,
